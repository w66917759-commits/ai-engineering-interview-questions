# Contributing

Thanks for improving the question bank.

## Report a correction

Include the question ID, the wording that needs correction, a proposed explanation, and a primary technical reference. Include the relevant product or library version when behavior depends on it.

## Add or improve a question

- Write original prompts and answers, or identify material whose license permits the proposed reuse and include the required attribution. Do not submit copied private interview materials, third-party question compilations, credentials, or customer data.
- Prefer concrete engineering decisions, testable failure modes, and explicit tradeoffs. Distinguish hypothetical examples from measured results.
- Explain why an answer works and where it stops applying. Avoid unsupported savings percentages, rankings, or employer claims.
- Give the question a stable ID, select an existing topic when appropriate, and include primary references and a real review date.
- Update both the relevant Markdown file and `data/questions.json`. Verify counts and local links in the README.
- Run `npm test` with Node.js 22 or newer to check the question snapshot and Markdown consistency.

## Translations

Preserve question IDs and technical meaning, identify the source language/version, and state that the translation is a community contribution. Keep the English source available for review.

Contributions must be eligible for distribution under this repository's CC BY 4.0 content license. Retain any third-party attribution and applicable license notices.
